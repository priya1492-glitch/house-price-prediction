About this project

A Bengaluru-focused regression demo that estimates property prices from area and location features.

Objective

Estimate a Bengaluru property's price using its area, BHK, bathrooms, balconies, availability and locality.

It is a regression problem: the target (price) is a continuous number.

Dataset

The supplied cleaned Bengaluru dataset contains 9,729 property records. Prices are shown in Indian rupees.

This project uses property area, BHK, bathrooms, balconies, readiness, area type and Bengaluru location.

Place the cleaned file at data/bengaluru_clean.csv and run python train_model.py to retrain.

Machine learning approach

  • Preprocessing: missing numbers are filled with the median and missing categories with the most common value. Numbers are standardized and locations/area types are one-hot encoded. These steps are fitted on training data only to avoid data leakage.
  • Linear Regression: a simple, fast baseline that fits a weighted sum of the features.
  • Random Forest Regressor: many decision trees averaged together. It can capture non-linear effects and feature interactions.
  • Model selection: 5-fold cross-validation on the training set; the lowest RMSE wins. The test set is used only for the final report.

Evaluation metrics

  • MAE (mean absolute error): the average size of the mistakes, in rupees.
  • RMSE (root mean squared error): like MAE but penalises large mistakes more.
  • R²: the share of price variation the model explains. 1.0 is perfect; 0 is no better than guessing the average.

Real-world uses

  • Giving buyers and sellers a quick first price idea.
  • Helping agents and investors compare properties and neighborhoods.
  • Supporting budgeting and planning for development or renovation.
  • Teaching how a full machine learning workflow fits together.

Limitations

  • The data represents Bengaluru listings and may not reflect today's market or other cities.
  • Only the listed features are used. Condition, renovations, views and market timing are not captured.
  • An estimate is not an appraisal. The typical error is shown with each result.
